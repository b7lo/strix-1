# مراجعة قواعد المسؤولية — Phase 5

**الحالة:** `DEFERRED_NO_REVIEWER` — تعذر توفير مختص مروري/قانوني في المرحلة الحالية.
**التاريخ التقني:** 2026-08-17
**النطاق:** سجل القواعد `STRIX-*`، الأدلة المطلوبة، الأدلة المعارضة، والسلم `[0, 25, 50, 75, 100]`.

## قرار المخاطر المؤقت

بتأكيد مالك المشروع بتاريخ 2026-08-17، لا يتوفر مراجع خارجي ولا يمكن توفيره
حاليًا. لا تُعامل هذه الحالة كموافقة قانونية بديلة. بدل تعطيل التطوير بالكامل،
تُطبق الضوابط الآتية حتى إجراء مراجعة مستقبلية:

- تبقى جميع القواعد `reviewed: false`.
- لا يمكن لأي قاعدة غير مراجعة إصدار `liabilityConclusive=true`.
- تعرض المسؤولية كنطاق تقديري، لا كحكم قطعي.
- يظهر القيد `liability.rule-not-legally-reviewed` ضمن أسباب خفض الثقة.
- يمنع وصف القواعد بأنها رسمية أو قانونية أو معتمدة من المرور أو التأمين.
- لا تستخدم النتيجة لاتخاذ قرار قانوني أو تأميني آلي.

## ضوابط ما قبل المراجعة

- جميع القواعد موسومة برمجيًا `reviewed: false`.
- النتائج توصَف كتقدير هندسي قابل للمراجعة، لا كحكم قانوني أو قاعدة مرور معتمدة.
- السرعة لا تغيّر المسؤولية مباشرة من نسبة سرعتي الطرفين.
- مخالفة السرعة لا تُضاف إلا كدليل مستقل عند توفر حد طريق موثوق.
- ضعف الاتجاه أو تعارض فرضيات السيناريو يمنع النتيجة القطعية ويوسع نطاق المسؤولية.
- كل نتيجة مرتبطة بمعرف قاعدة وأدلة وقيود قابلة للعرض.

## قائمة القواعد المطلوب اعتمادها أو تعديلها

- `STRIX-REAR-001`: تماس خلفي وزواياه والاصطدام المتسلسل.
- `STRIX-FRONT-001`: تماس أمامي مباشر وزواياه.
- `STRIX-SIDE-001`: تماس جانبي أو احتكاك.
- `STRIX-LANE-001`: تغيير/دمج مسار مع دليل yaw.
- `STRIX-INTERSECTION-001`: تقاطع/دوار مع دليل أولوية.
- `STRIX-U-TURN-001`: دوران U مع yaw مستمر.
- `STRIX-PARKING-001`: مناورات الوقوف وفتح الباب.
- `STRIX-CROSS-CONTACT-001`: إعادة بناء تماس تقريري الطرفين.
- `STRIX-UNKNOWN-001`: حالة احتياطية غير قطعية.

## أسئلة المراجع الخارجي

1. هل شروط كل قاعدة كافية، وما الأدلة الإلزامية الناقصة؟
2. هل توجد حالة يجب منع إصدار نسبة مسؤولية فيها بالكامل؟
3. هل السلم القانوني المستخدم مناسب لكل سياق مستهدف؟
4. هل صياغة الأدلة والقيود تمنع فهم النتيجة كحكم رسمي؟
5. هل يلزم فصل قواعد حسب الدولة أو الجهة التنظيمية؟
