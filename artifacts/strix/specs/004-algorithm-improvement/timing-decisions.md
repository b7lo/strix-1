# Phase 2 Timing Decisions

## الهدف

توحيد سلوك المحرك بين الأجهزة التي تقدم معدلات عينات مختلفة أو متذبذبة، ومنع القسمة على صفر أو تضخم jerk عند timestamps غير صالحة.

## القرارات

### الزمن هو المصدر الأساسي

- تستخدم الخوارزميات `timestamp` و`dt` الفعليين.
- معدل الإعداد يبقى fallback فقط قبل توفر عينات كافية.
- شروط المناورة تقاس بالمللي ثانية بدل عدد العينات.

### تطبيع timestamps

`SampleClock` يحول timestamps إلى تسلسل أحادي التزايد:

- timestamp مكرر: يسجل `duplicate` ويتقدم بفترة fallback.
- timestamp أقدم: يسجل `out-of-order` ويتقدم بفترة fallback.
- فجوة كبيرة: تحفظ زمنيًا وتسجل `gap` ولا تخفى.
- timestamp غير منتهٍ: يستخدم fallback آمن.

يفصل زمن المصدر عن الزمن المطبع حتى لا تسبب عينة سيئة سلسلة أخطاء لاحقة.

### حساب المعدل

يستخدم `SampleRateEstimator` median لفترات العينات، وmedian absolute deviation مبسطًا لقياس jitter. لا يدخل gap في حساب المعدل الطبيعي حتى لا يخفضه بصورة مضللة، لكنه يظهر كقيد جودة مستقل.

### الحدود الزمنية الحالية

| الحدث | المدة |
|---|---:|
| استقرار baseline | 5 ثوانٍ |
| فرملة `analyzeBraking` | 100ms |
| فرملة قوية قبل الحادث | 200ms |
| تسارع قوي قبل الحادث | 160ms |
| نافذة قمة الاصطدام | 300ms |
| نافذة تحليل الفرملة | ثانيتان |

هذه الحدود تحفظ تقريبًا معنى القيم السابقة عند 50Hz، وتحتاج معايرة ميدانية لاحقة.

### Kalman وEMA

- Process noise في Kalman يضرب بنسبة `dt / 20ms` ضمن حدود آمنة.
- معامل EMA لفاصل التردد يعاد حسابه من `dt` وcutoff مقداره 5Hz.
- معامل تتبع الجاذبية مشتق من ثابت زمني يحافظ على سلوك 50Hz السابق.

### Resampling

- الهدف الافتراضي للاختبارات 50Hz.
- interpolation خطي داخل الفجوات القصيرة فقط.
- لا يتم اختلاق نقاط داخل gap أكبر من الحد الآمن.
- التسجيل الخام لا يستبدل بالبيانات المعاد أخذها؛ resampling طبقة تحليل اختيارية.

## جودة البيانات

تخفض الجودة عند:

- وجود gaps.
- jitter أكبر من نصف الفترة المعتادة وبحد أدنى 5ms.
- timestamps مكررة أو غير مرتبة.

يظهر سبب الخفض في `dataQualityLimitations` ولا يخفى داخل رقم واحد.

## معايير القبول

- ثبات اكتشاف صدمة قوية ومنطقتها عند 25/50/100Hz.
- عدم إنتاج NaN أو Infinity.
- عدم interpolation عبر gaps كبيرة.
- بقاء baseline Phase 0 دون regression غير مبرر.
